# AsyncioAndMultiprocessing

Проект **School 21 / Python_Bootcamp** по практическому освоению **асинхронного и многопроцессного программирования** на Python.

## О проекте

Проект состоит из двух практических заданий, объединённых одной темой — одновременное выполнение нескольких задач. В нём рассматриваются четыре парадигмы программирования (ООП, процедурная, функциональная и мультипарадигмальная) и их применение в реальных сценариях с конкурентностью.

## Задание 1. Симуляция экзамена (multiprocessing)

**Суть:** многопроцессная модель сдачи экзамена, где каждый экзаменатор работает в отдельном процессе.

- Студенты стоят в **общей очереди**, экзаменаторы берут следующего студента по мере освобождения.
- Через 30 секунд после начала экзаменатор уходит на **обед** (пауза 12–18 секунд).
- Ответы моделируются по **закону золотого сечения**: мальчики чаще выбирают слова из начала вопроса, девочки — из конца; несколько верных ответов допустимо.
- Настроение экзаменатора (плохое/хорошее/нейтральное) с вероятностями 1/8, 1/4 и 5/8 влияет на результат.
- Длительность экзамена зависит от длины имени экзаменатора.
- Промежуточная и финальная статистика выводится в виде таблиц, обновляемых на месте: статусы студентов, загруженность экзаменаторов, очередь, время.
- По итогам определяются лучшие студенты, лучшие экзаменаторы, отчисляемые студенты, лучшие вопросы и общий результат (экзамен считается успешным при > 85 % сдавших).

**Технологии:** `multiprocessing` (процессы, очереди, разделяемая память, менеджер, блокировки, события).

## Задание 2. Асинхронное скачивание изображений (asyncio)

**Суть:** обработчик ссылок, который асинхронно скачивает изображения по URLs, не блокируя ввод новых ссылок.

- Пользователь вводит пути сохранения и ссылки на изображения; ввод новых ссылок продолжается сразу, не дожидаясь завершения загрузки.
- Скачивание выполняется **асинхронно**, параллельно с вводом.
- Ошибки не прерывают программу — сохраняется статус каждой попытки для итоговой сводки.
- При некорректном пути предлагается ввести другой, директория создаётся автоматически.
- В конце выводится таблица-сводка успешных и неуспешных загрузок.
- Интерактивный интерфейс на `curses` с отображением прогресса загрузки в реальном времени.

**Технологии:** `asyncio` + `threading`, `requests`, `curses`, `prettytable`.
